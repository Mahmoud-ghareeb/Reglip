### The idea in one paragraph

SigLIP uses binary cross-entropy over the pairwise similarity matrix: each image-text pair is labelled as either a match (1) or not (0). We propose **RegLIP**, which replaces these binary targets with **continuous similarity scores** generated by a frozen large text encoder (Qwen3-Embedding-8B). Instead of "match or not," the model learns "how similar," using MSE regression. The architecture is unchanged — same ViT, same text encoder, same projection heads. The only difference is the loss function.

### Preliminary results

We ran two controlled experiments using `siglip-base-patch16-224` on Flickr30K (31K pairs):

| Experiment                   | Setting                       | Result                                                                                  |
| ---------------------------- | ----------------------------- | --------------------------------------------------------------------------------------- |
| **1. Fine-tuning**     | All parameters trained        | RegLIP outperforms SigLIP on all 5 benchmarks (e.g., CIFAR-10:**47.4%** vs 24.6%) |
| **2. Frozen backbone** | Only projection heads trained | Mixed — SigLIP wins coarse tasks, RegLIP wins fine-grained + top-5 ranking             |

These results are promising but limited: Flickr30K is tiny (31K pairs), and the models start from SigLIP pre-trained weights, introducing a bias toward the original loss. **A fair conclusion requires training from scratch on the same data and scale as the original SigLIP.**
