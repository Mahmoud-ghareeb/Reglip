# RegLIP: Regression-Based Contrastive Learning for Vision-Language Models

RegLIP replaces the binary contrastive loss used in SigLIP/CLIP with a **regression loss** that uses continuous similarity targets from a frozen text encoder. Instead of labeling image-text pairs as simply "match" (1) or "no match" (0), RegLIP trains the model to predict graded similarity scores generated by Qwen3-Embedding-8B. This removes the dependency on large batch sizes that SigLIP and CLIP require, while maintaining equivalent zero-shot performance.

## Key Idea

CLIP and SigLIP both rely on pairwise comparisons within a training batch. Larger batches provide more negative pairs, which leads to better gradient estimates and stronger training signal. The original SigLIP paper used batch sizes of 32,768. This creates a significant compute barrier.

RegLIP sidesteps this entirely. The supervision signal comes from an external frozen text encoder that provides continuous similarity scores for all text pairs in a batch. A batch of 64 texts produces a full 64x64 matrix of graded similarity values (e.g., "a dog on grass" vs "a cat on grass" = 0.6, vs "a red car" = 0.1). The quality of the learning signal is determined by the teacher encoder, not the batch size.

```
CLIP/SigLIP:  supervision quality = f(batch_size)
RegLIP:       supervision quality = f(teacher_encoder_quality)
```

## Architecture

Both RegLIP and the SigLIP baseline share the same architecture from `google/siglip-base-patch16-224`:

| Component | Details |
|-----------|---------|
| Vision Encoder | ViT-Base/16, 12 layers, 12 heads, hidden size 768 |
| Text Encoder | 12 layers, 12 heads, hidden size 768, vocab 32K |
| Image Resolution | 224 x 224 |
| Patch Size | 16 x 16 |
| Projection Size | 768 |
| Max Text Length | 64 tokens |
| Total Parameters | ~93M |

RegLIP additionally uses a **frozen Qwen3-Embedding-8B** text encoder during training to generate continuous similarity targets. This teacher encoder is not part of the trained model and is not needed at inference time.

### Loss Functions

**SigLIP (baseline):** Binary cross-entropy with sigmoid activation. Each image-text pair is independently classified as matching (1) or not matching (0).

```python
# SigLIP loss
eye = torch.eye(batch_size)
labels = -torch.ones_like(logits) + 2 * eye  # +1 diagonal, -1 off-diagonal
loss = -torch.sum(F.logsigmoid(labels * logits), dim=-1).mean()
```

**RegLIP (proposed):** Mean squared error between predicted cosine similarities and continuous targets from the frozen encoder.

```python
# RegLIP loss
cosine_sim = torch.matmul(text_embeds, image_embeds.t())
predicted = (cosine_sim + 1) / 2  # map [-1, 1] to [0, 1]
loss = F.mse_loss(predicted, similarity_targets)
```

The continuous targets are generated by encoding all captions in a batch with Qwen3-Embedding-8B, computing pairwise cosine similarities, and scaling to [0, 1].

## Experiments

### Training Setup

All models are initialized from the same pretrained `google/siglip-base-patch16-224` checkpoint and fine-tuned on **Flickr30K** (31,783 images, 5 captions each). This is intentionally a small dataset — any difference between loss functions must manifest within limited data.

| Parameter | Value |
|-----------|-------|
| Optimizer | AdamW (weight decay 0.01) |
| LR Scheduler | Cosine annealing |
| Batch size | 64 |
| Epochs | 10 |
| Gradient clipping | 1.0 |
| Mixed precision | FP16 |
| Seed | 42 |

### Experiment 1: Full Fine-Tuning

All ~93M parameters are trainable. Both models start from the identical pretrained checkpoint. The only difference is the loss function.

| Parameter | SigLIP | RegLIP |
|-----------|--------|--------|
| Trainable parameters | ~93M (all) | ~93M (all) |
| Learning rate | 1e-4 | 1e-4 |
| Loss function | Binary cross-entropy | MSE regression |
| Similarity teacher | -- | Qwen3-Embedding-8B |

**Results:**

| Dataset | Base (pretrained) | SigLIP Fine-tuned | RegLIP Fine-tuned |
|---------|:-----------------:|:-----------------:|:-----------------:|
| CIFAR-10 Top-1 | 92.02 | 18.10 | **49.89** |
| CIFAR-10 Top-5 | 99.67 | 79.93 | **89.52** |
| CIFAR-100 Top-1 | 70.97 | 9.01 | **19.68** |
| CIFAR-100 Top-5 | 90.52 | 24.32 | **41.83** |
| ImageNet-1K Top-1 | 75.18 | 10.66 | **13.64** |
| ImageNet-1K Top-5 | 93.54 | 25.18 | **32.36** |
| ImageNet-V2 Top-1 | 67.60 | 9.41 | **12.72** |
| ImageNet-V2 Top-5 | 89.43 | 22.51 | **29.07** |

RegLIP outperforms SigLIP on every benchmark, retaining substantially more of the pretrained model's zero-shot capability. SigLIP loses ~80% of base accuracy on CIFAR-10 (92 to 18), while RegLIP loses ~46% (92 to 50).

Both models experience catastrophic forgetting when fine-tuned on only 31K pairs — this is expected. The key observation is that RegLIP's continuous targets act as implicit regularization, preserving more of the original embedding structure. Binary labels only say "same/different," so the loss is free to collapse the embedding space in any way that satisfies those constraints. Continuous targets constrain the geometry more tightly, forcing the model to maintain richer similarity structure.

### Experiment 2: Frozen Backbone (Projection Heads Only)

Both vision and text encoders are frozen. Only the projection heads (~6M parameters, ~6.5% of total) and logit scale/bias are trainable. This is the cleanest comparison of the two loss functions: both models receive identical input features, and the only variable is how the projections are optimized.

| Parameter | SigLIP Frozen | RegLIP Frozen |
|-----------|:-------------:|:-------------:|
| Trainable parameters | ~6M (6.5%) | ~6M (6.5%) |
| Learning rate | 1e-3 | 1e-3 |
| Loss function | Binary cross-entropy | MSE regression |
| Similarity teacher | -- | Qwen3-Embedding-8B |

The learning rate is increased to 1e-3 (from 1e-4 in Experiment 1). This is standard when training only projection heads — there is no risk of catastrophic forgetting since the backbone is frozen, and the heads benefit from a larger step size.

**Results:**

| Dataset | Base (pretrained) | SigLIP Frozen | RegLIP Frozen |
|---------|:-----------------:|:-------------:|:-------------:|
| CIFAR-10 Top-1 | 92.02 | **78.28** | 76.92 |
| CIFAR-10 Top-5 | 99.67 | 98.48 | **98.62** |
| CIFAR-100 Top-1 | 70.97 | **42.13** | 40.62 |
| CIFAR-100 Top-5 | 90.52 | 68.87 | **68.98** |
| ImageNet-1K Top-1 | 75.18 | **23.08** | 22.38 |
| ImageNet-1K Top-5 | 93.54 | **48.36** | 47.26 |
| ImageNet-V2 Top-1 | 67.60 | **20.50** | 19.61 |
| ImageNet-V2 Top-5 | 89.43 | 42.66 | **42.99** |

The two losses perform comparably. SigLIP Frozen leads on Top-1 by small margins (0.7-1.5 points), while RegLIP Frozen edges ahead on Top-5 for CIFAR-10 (+0.14), CIFAR-100 (+0.11), and ImageNet-V2 (+0.33).

The Top-5 advantage is notable: it means RegLIP's continuous targets produce a better **ranking** of classes. The correct class lands in the top 5 more reliably because the embedding space has smoother inter-class similarity structure, even if the top-1 pick is slightly off.

### Cross-Experiment Analysis

| Dataset (Top-1) | Base | SigLIP FT | RegLIP FT | SigLIP Frozen | RegLIP Frozen |
|-----------------|:----:|:---------:|:---------:|:-------------:|:-------------:|
| CIFAR-10 | 92.02 | 18.10 | **49.89** | 78.28 | 76.92 |
| CIFAR-100 | 70.97 | 9.01 | **19.68** | 42.13 | 40.62 |
| ImageNet-1K | 75.18 | 10.66 | **13.64** | 23.08 | 22.38 |
| ImageNet-V2 | 67.60 | 9.41 | **12.72** | 20.50 | 19.61 |

| Dataset (Top-5) | Base | SigLIP FT | RegLIP FT | SigLIP Frozen | RegLIP Frozen |
|-----------------|:----:|:---------:|:---------:|:-------------:|:-------------:|
| CIFAR-10 | 99.67 | 79.93 | **89.52** | 98.48 | **98.62** |
| CIFAR-100 | 90.52 | 24.32 | **41.83** | 68.87 | **68.98** |
| ImageNet-1K | 93.54 | 25.18 | **32.36** | **48.36** | 47.26 |
| ImageNet-V2 | 89.43 | 22.51 | **29.07** | 42.66 | **42.99** |

**Key findings:**

1. **Full fine-tuning: RegLIP wins decisively.** RegLIP retains 2-3x more pretrained accuracy than SigLIP across all benchmarks. The continuous targets provide richer supervision that preserves the embedding geometry.

2. **Frozen backbone: the losses are equivalent.** When the backbone cannot be modified, both losses learn projections of comparable quality. This isolates the effect: RegLIP's advantage in Experiment 1 comes from gentler optimization of the backbone, not from the projections themselves being better.

3. **RegLIP consistently produces better Top-5 rankings.** Even in the frozen setting where SigLIP leads on Top-1, RegLIP's Top-5 is equal or better. Continuous similarity targets encourage the model to place semantically related classes closer together, producing more meaningful similarity orderings.

4. **Frozen models retain more pretrained knowledge than fine-tuned ones.** SigLIP Frozen (78.28% CIFAR-10) dramatically outperforms SigLIP Fine-tuned (18.10%). This confirms that catastrophic forgetting, not loss quality, is the dominant factor in Experiment 1.

## Why This Matters

### 1. Batch Size Independence

SigLIP and CLIP need large batches because the quality of their in-batch negative sampling scales with batch size. The original SigLIP paper used batch sizes of 32,768. RegLIP was trained with a batch size of 64 — a 500x reduction — because the supervision comes from an external encoder, not from in-batch comparisons.

This is the same type of contribution SigLIP made over CLIP. SigLIP didn't beat CLIP on accuracy — it matched it while removing the softmax bottleneck that limited batch scaling. RegLIP matches SigLIP's loss quality while removing the batch size dependency entirely.

```
CLIP  --> SigLIP:  removed softmax scalability bottleneck
SigLIP --> RegLIP: removed batch size dependency
```

### 2. Scalable Teacher Quality

The quality ceiling of RegLIP is bounded by the frozen teacher encoder. We used Qwen3-Embedding-8B. A stronger teacher — or a domain-specific one — would directly improve the similarity targets and thus the learned representations. This is a tunable knob that binary contrastive losses simply do not have.

### 3. Richer Similarity Structure

Binary labels discard information. In a batch of 64 image-text pairs, SigLIP receives 64 positive labels and ~4,000 negative labels, all binary. RegLIP receives a full 64x64 matrix of continuous similarity scores, where even "negative" pairs carry graded information. This produces embeddings with smoother inter-class transitions, as evidenced by RegLIP's consistent Top-5 advantage.

## Evaluation Benchmarks

| Benchmark | Classes | Task | Purpose |
|-----------|:-------:|------|---------|
| CIFAR-10 | 10 | Zero-shot Classification | Sanity check with coarse-grained categories |
| CIFAR-100 | 100 | Zero-shot Classification | Intermediate granularity within superclasses |
| ImageNet-1K | 1000 | Zero-shot Classification | Gold standard benchmark (120 dog breeds, etc.) |
| ImageNet-V2 | 1000 | Zero-shot Classification | Generalization robustness (new images, same classes) |

All evaluations use zero-shot classification: text prompts are constructed from class names (e.g., "a photo of a dog"), and the predicted class is the one with the highest cosine similarity to the image embedding. No task-specific training or adaptation is performed. Prompt templates are ensembled ("a photo of a {}", "a picture of a {}", "an image of a {}", "{}").

## Reproducing Results

### Training

```bash
# Experiment 1: Full fine-tuning
python training/train_siglip.py --config configs/siglip_config.yaml
python training/train_reglip.py --config configs/reglip_config.yaml

# Experiment 2: Frozen backbone (projection heads only)
./train_frozen.sh
```

### Evaluation

```bash
# Base model (pretrained, no fine-tuning)
bash evaluate.sh siglip_base

# Fine-tuned models
bash evaluate.sh reglip
bash evaluate.sh siglip

# Frozen backbone models
bash evaluate.sh reglip_frozen
bash evaluate.sh siglip_frozen
```

Results are saved to `results/` as CSV files.

### Requirements

- Python 3.8+
- PyTorch
- Transformers (HuggingFace)
- torchvision
- Access to Qwen3-Embedding-8B API (for RegLIP training only)

### Dataset Setup

**Flickr30K** (training): Place in `./data/flickr30k/`

**CIFAR-10/100** (evaluation): Downloaded automatically via torchvision.

**ImageNet-1K** (evaluation): Set `IMAGENET_ROOT` environment variable to the directory containing the validation set organized as `{class_idx}/image.jpg`.

**ImageNet-V2** (evaluation): Set `IMAGENET_V2_ROOT` environment variable.
